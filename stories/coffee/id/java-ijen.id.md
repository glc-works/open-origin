Arabika Jawa berpusat di Dataran Tinggi Ijen di ujung timur pulau, di atas 1.400 meter. Kopinya kebanyakan tumbuh di perkebunan besar yang dibangun Belanda; lima yang terbesar adalah Blawan, Jampit, Pancoer, Kayumas, dan Tugosari [1]. Kebun seperti Jampit, Blawan, dan Pancur lama dikelola perusahaan perkebunan negara PTPN XII [2]. Sejak PTPN XII bergabung ke PTPN I pada 2023, kebun-kebun itu dikelola PTPN I Regional 5 dengan nama Java Coffee Estate [5].

Perkebunan membawa buah matang dengan cepat ke pabriknya, tempat daging buah difermentasi lalu dicuci (proses basah) [1]. Di sekitarnya, petani rakyat di lereng Ijen dan Raung menanam kopi sendiri. Sejak 2016 Bondowoso menjuluki dirinya "Republik Kopi" untuk mengangkat mereka [2][3], dan Kopi Arabika Java Ijen-Raung memperoleh Indikasi Geografis pada 2013 [4].

Kopi Jawa adalah bagian klasik dari campuran "Mocha Java", dan sebagian perkebunan menyimpan sebagian kopinya selama bertahun-tahun, sehingga asamnya melunak [1].
