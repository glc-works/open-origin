# Open Origin brand

The mark is three contour lines of a hill around the point of origin, in forest green, leaf green and teal. The wordmark is lowercase **open origin** in Bricolage Grotesque (open: 700, muted grey; origin: 800, ink), converted to outlines so it looks the same everywhere.

| File | Use |
|---|---|
| `mark.svg` / `mark-dark.svg` | The mark on light / dark backgrounds |
| `mark-black.svg` / `mark-white.svg` | One-colour printing, stamps, embroidery |
| `lockup.svg` / `lockup-dark.svg` | Mark + wordmark on light / dark backgrounds |
| `lockup-black.svg` / `lockup-white.svg` | One-colour mark + wordmark |
| `badge.svg` | App icon, sticker, pin, social avatar |
| `origin-*.svg` | Section names: origin stories, lots, producers, codes, learn, data |
| `../logo.svg` | Favicon; follows the browser's light or dark mode |
| `motion/intro.svg` / `motion/intro-lockup.svg` | Animated mark (and mark + wordmark): the point of origin appears, closed contour rings draw around it, then a path opens through them from the outside in to the origin. For video intros and splash screens |
| `motion/loading.svg` | Loading indicator for data: the contours build up from data points, then the point of origin lights up. Loops |

Colours: forest `#26432E`, leaf `#355E40`, teal `#1F5F6B`, ink `#1C1D18`, muted `#5B5E52`. On dark backgrounds: `#7FB08A`, `#7FB6C2`, `#E6E6DC`, `#A1A496`.

Section names follow one rule: **origin** is always bold and dark, the second word is lighter and grey.

Both animations are plain SVG with CSS (no script) and stop on the final frame when the viewer has asked for reduced motion.

Leave clear space around the mark of at least the width of its centre ring. Don't recolour it in orange or red, stretch it, or add effects.

The logo is part of this repository (Apache-2.0). Use it to point to Open Origin; don't use it in a way that suggests Open Origin endorses a product or a lot.
